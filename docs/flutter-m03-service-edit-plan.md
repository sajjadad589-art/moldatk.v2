# M03 service change calculation preview

Reviewed legacy SubscriberModal edit behavior: current unpaid/partial invoices are repriced, paid/free/zero-charge/lump-settlement invoices preserved, historical invoices not rewritten. The legacy code clamps already-paid cash to the new charge; this candidate refuses a price below collected cash rather than silently erasing money. Discount supports half-ampere increments as in legacy; fractional IQD is refused rather than rounded. It requires full, validated invoice history and one active noncancelled current invoice; the existing 50-row detail preview is insufficient. Free-tier transitions, absent active invoice creation, exact tier identity resolution, and line reassignment require separate server validation. This is an unmounted pure calculation, not an edit transaction; no write API or production change. Seven tests added. Protected rows are not repriced; newGross/newDiscount are only meaningful when reprice=true.
