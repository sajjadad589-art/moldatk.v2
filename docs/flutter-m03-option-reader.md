# M03 subscriber option reader

Read-only authenticated staging adapter for generator_lines, generator_monthly_tariffs and the current collector permission row, based on main cloudSyncRows.ts and collectorCloud.ts. Requires one explicit active tariff, rejects foreign rows, limits results and fails closed on truncation, rejects noninteger money, and intersects collector assignments with visible lines. No active marker disables previews rather than guessing the newest month; verify this stricter behavior against real staging data. No live query or production changes were performed. Before mounting the form, serialize the reader with session checks and invalidate the preview on permission or tariff changes; server-side save must independently enforce all permissions and use an atomic transaction. A separate staging project is still missing.
