# M05 authenticated collection coordinator

Connects immutable payment intent, secure pending storage, SessionController authorization, verified receipt and archival. A fresh collection cannot reuse any pending operation; status-only recovery is required instead. The staging session gateway now has explicit collection/status transport methods using a fixed HTTPS staging URL, current authenticated JWT, publishable key and per-request epoch header, no redirects or automatic retries. Hosted transport is disabled by default and has no UI caller; fixture SQL refuses hosted installation. Four tests cover persistence before dispatch, lost response, invalid receipt and disabled transport. No production data or API change. A real hosted staging project, RPC environment guard and end-to-end device run remain required before exposing a collect button. No offline authorization.
