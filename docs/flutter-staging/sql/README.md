# M03 atomic SQL candidate

The SQL under this directory is a review candidate, intentionally outside supabase/migrations and not deployed. Production catalog inspection (metadata only) verified subscriber/invoice/audit/line/tariff columns, composite primary keys, unique generator/code, invoice foreign keys, and the signatures of get_my_subscription_access_state and moldatk_recount_generator_line. Existing reset migration uses advisory lock 89144 and an x-moldatk-sync-epoch request header.

The draft is owner-only, in an unexposed private schema, with all client execution revoked. It derives tenant from auth.uid/profile, checks active subscription, locks reset scope, checks expected epoch and existing request fingerprint, recomputes debt from the selected historical tariff, creates subscriber and marker/debt invoices, recounts line, adds audit and receipt in one transaction. No cashbox writes. Reset/replay after deletion is rejected. Code generation uses the request UUID to avoid a short random collision; final display convention needs approval. No public RPC wrapper or client save action yet.

Before enabling: obtain isolated staging, confirm schema and triggers against staging, inspect live reset/subscription function definitions, check audit category conventions and invoice snapshot fields, verify tariff status/locking against legacy writers and parallel changes, test all rollback/retry/tenant/expiry/reset cases and compare actual post-trigger ledger state, review SECURITY DEFINER privileges and run advisors. The command must also capture epoch and send its header; no override of trigger checks. Collector support requires review of existing invoice permission triggers. The draft is not syntax-tested or executed. No migration to production was performed.
