# Authenticated integration boundary

Six fixture-only SQL RPC wrappers exercise the same command and epoch contract as a future PostgREST interface. Installation and invocation are hard-blocked outside the disposable database named moldatk_fixture. Only authenticated has EXECUTE, private candidates remain private, and wrappers preserve actor authorization and strict epoch header. The role regression exercises actual authenticated-role create/replay, collector denial, missing actor and stale epoch. This fixture does not implement a real hosted staging API or JWT verification; fixture GUCs simulate identity, and direct SQL role tests are not full Supabase RLS/PostgREST tests. Do not deploy this file to production. Hosted staging wrapper design, isolated integration data and HTTP tests remain required.
