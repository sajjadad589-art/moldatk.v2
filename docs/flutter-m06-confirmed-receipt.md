# M06 confirmed receipt payload

Collection candidate records original subscriber name/code/phone/line/amperes, collector and active-month price in the private immutable response. Status lookup returns that same response on a committed payment. Flutter maps verified amounts and original identity to the native receipt field contract, uses Baghdad time and refuses unknown/reversed or snapshotless status. QR is deliberately disabled until a verified portal token can be fetched. Three Dart tests and a SQL snapshot assertion added. The mapper is not connected to a live status endpoint or financial print submission; existing receipt templates, exact generator identity at collection, portal QR, hardware tests and authenticated staging transport remain necessary. Production unchanged.
