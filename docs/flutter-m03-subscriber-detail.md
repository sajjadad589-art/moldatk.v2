# M03 subscriber detail preview

The owner can open a subscriber from the read-only list to see identity, line, amperes, server-recorded outstanding amount, payment status and up to 50 recent invoice summaries. Financial detail is intentionally not offered to collectors pending permission parity. The reader scopes both tables to tenant and subscriber, validates every returned invoice, brackets the reads with the reset epoch and requires the serialized authorized session. This is not an atomic financial snapshot; concurrent billing edits can still change values between queries. No payment or edit controls are enabled. Existing periodic access checks remount and refresh the detail. Actual RLS, full history pagination, device UX and transactional reconciliation need staging tests.
