# Line move review candidate
Owner-only move of an existing subscriber to an exact line ID in the same generator. Locks the reset scope and subscriber version, validates subscription and idempotency, updates only line identity and timestamp, recounts both lines and audits the operation atomically. The fixture tests unchanged invoices and debt, rejection of foreign line and stale version, replay, and both loads. No capacity cap is imposed because the legacy assignment policy has not been verified; capacity warnings/limits and real trigger compatibility must be reviewed before rollout. No public RPC grant, app write or production migration.
