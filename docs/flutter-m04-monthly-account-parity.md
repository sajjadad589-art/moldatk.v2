# Monthly account projection review

Legacy financial-integrity migration 20260915065500 derives carried debt from earlier tariff creation order, current paid from canonical current invoice, total remaining from both. This candidate accepts only account rows whose existing monthly charge, current paid, carried debt and remaining already match the canonical chronological month-ID ledger. Inconsistent or missing-tariff rows fail closed; no new account rows are synthesized. After payment it recomputes the existing monthly projections, preserves charge and nonfinancial fields, and uses the legacy status rule. **Limitation:** tariff creation order can differ from calendar order; the candidate still needs an explicit chronology compatibility check and real staging test before release. The disposable fixture now includes reconciled historical and current accounts and checks both projections after a payment, while preserving previous rollback/replay tests. No production migration or data access.
